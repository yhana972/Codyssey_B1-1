SECTION 01 / ABOUT

Poolside Introduction

클라이언트 개발에서 시작해 더 넓은 서비스 개발로

약 6년간 웹과 XR을 비롯한 클라이언트 개발을 경험했습니다. Unity와 C#을 활용한 XR 콘텐츠부터 Android와 Web 환경까지, 다양한 플랫폼에서 사용자가 직접 마주하는 화면과 기능을 개발해왔습니다.

현재는 기존 클라이언트 개발 경험을 기반으로 React와 Flutter 같은 Web/App 기술뿐 아니라 Python, FastAPI, AI API를 활용한 서비스 개발까지 영역을 확장하고 있습니다.

특정 플랫폼에 한정되기보다 사용자 경험과 서비스의 전체 흐름을 이해하고, 필요한 기술을 연결해 실제 동작하는 결과물을 만드는 개발자를 지향합니다.
